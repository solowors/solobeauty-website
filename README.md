# SoloBeauty Website

Professional cosmetics brand website inspired by **Rare Beauty** and **Rhode**.

## Features
- Clean, modern design with soft plum & blush color palette
- Smooth scroll animations & hero zoom
- Product grid with hover effects and Quick Add
- Category sections, brand story, community gallery
- Fully responsive single-file HTML (no build step)

## How to view
1. Open `index.html` in any browser, or
2. Enable GitHub Pages (Settings → Pages → Deploy from main)

## Brand
**SoloBeauty** — Makeup that feels like you. Clean formulas. Inclusive shades.
